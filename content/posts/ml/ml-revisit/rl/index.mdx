Reinforcement learning 关心的是如何通过与环境交互，学到让长期期望 return 更高的 policy。这组笔记沿着「估计梯度 → 更新策略 → 用于语言模型 → 处理采样偏差」展开。

## Reading order

1. [Policy Gradient 与 Advantage Estimation](/blog/ml/ml-revisit/rl-policy-gradient)：从目标和轨迹出发，推导 REINFORCE，再用 baseline、critic 和 GAE 构造 advantage。
2. [从旧策略数据到 PPO](/blog/ml/ml-revisit/rl-policy-updates)：用 importance sampling 理解旧数据复用，再看 TRPO 与 PPO 如何控制策略变化。
3. [LLM Post-training](/blog/ml/ml-revisit/rl-llm)：整理 RLHF、DPO、GRPO；InstructGPT、DeepSeek-R1、RLVR 和 Reward Hacking 等未完成部分继续保留待续。
4. [Training-inference Mismatch 与 Score Centering](/blog/ml/ml-revisit/rl-score-centering)：从 mean-score drift 出发，比较 Score Centering、baseline、IS 与 BPO，并讨论实现和结论边界。

前两篇是基础主线。熟悉 policy gradient 和 PPO 后，可以直接阅读 LLM 应用或 mismatch 专题。

## Other directions

上面的主线显式优化 policy。这里保留 value-based 方法的开头，以及把 policy optimization 用于 diffusion models 的阅读入口。

### Q Learning

之前其实我们都显式维护一个 $\pi_\theta$，也可能通过 $\mathcal V$ 和 $\mathcal Q$ 来指导这个 policy 的更新。

那其实我们能不能直接根据 $\mathcal Q$ 来选 action？比如先选定一个最大值对应的 action $a^*(s)\in\arg\max_{a'}\mathcal Q(s,a')$，有并列时用固定规则处理，再定义

$$
\pi(a\mid s)=\begin{cases}
1,&a=a^*(s),\\
0,&\text{otherwise}.
\end{cases}
$$

后面的 Q-learning 更新与推导待续。
